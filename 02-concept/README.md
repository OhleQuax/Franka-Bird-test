# 02 · Konzept

Ideen, aus denen das Projekt entsteht.

| Ordner | Was kommt rein |
|---|---|
| `skizzen/` | Scribbles und erste Entwürfe (Fotos oder Scans) |
| `moodboards/` | Stimmung, Farbe, Form |
| `szenarien/` | Abläufe: Was passiert zwischen Mensch und Roboter, Schritt für Schritt |
| `zustaende/` | Roboter-Zustände wie OFF, READY, THINKING, NEED CLARIFICATION und wie sie aussehen |
