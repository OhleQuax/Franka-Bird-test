# 04 · Interface

Alles, was man sieht und womit man interagiert: Bildschirm, Licht, Sprache, Gesten.

| Ordner | Was kommt rein |
|---|---|
| `screens/` | Screendesigns und UI-Entwürfe (Exporte als `.png`, `.pdf`, `.svg`) |
| `licht-led/` | LED-Farben, Blinkmuster, Zustände |
| `sprache-sound/` | Sprachbefehle, Antworten des Roboters, Sounds |
| `prototypen/` | Klickbare oder programmierte Prototypen, z. B. HTML-Dateien |
