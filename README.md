# Franka Bird

Projekt von Group-Bird für Franka Robotics (M.A., Franka X Mu): Wie zeigt der FR3 Duo, was er wahrnimmt, denkt und vorhat?

## Ordner

| Ordner | Inhalt |
|---|---|
| [`00-organisation/`](00-organisation/) | Briefing, Meeting-Protokolle, Zeitplan |
| [`01-research/`](01-research/) | Referenzen, Nutzer, Technik des FR3 Duo, Erkenntnisse |
| [`02-concept/`](02-concept/) | Skizzen, Moodboards, Szenarien, Roboter-Zustände |
| [`03-3D/`](03-3D/) | Modelle, Posen, Renderings |
| [`04-interface/`](04-interface/) | Screens, Licht und LEDs, Sprache und Sound, Prototypen |
| [`05-materials/`](05-materials/) | Farben, Oberflächen, Material-Referenzen |
| [`06-presentation/`](06-presentation/) | Zwischenstände und finale Präsentation |

Die programmierten Prototypen liegen im Repo [Group-Bird/DES](https://github.com/Group-Bird/DES).

## Regeln

- **Dateinamen:** Datum vorne und ohne Leerzeichen, z. B. `2026-11-27_led-farben.png`.
- **Große Dateien** (`.blend`, `.psd`, `.ai`, Videos, über ca. 50 MB) bleiben in OneDrive. Hier nur den Link notieren.
- In jedem Ordner erklärt eine `README.md`, was hineingehört.
